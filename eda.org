* Introduction

** Objective
Zane Selvans' write-up for the GitHub issue is super detailed and has plenty of
references, so I'll simply link to the [[https://github.com/catalyst-cooperative/pudl/issues/3910][issue]] itself for an introduction. To
summarize: we wish to study any biases in the demand forecasts of regulated
utilities in the United States.

** Context
Utilities have historically overestimated load growth, and given that we are in
a fresh new hype cycle around large-scale data and artificial intelligence, it
is possible that utilities are using this hype as justification to build out
"emergency" infrastructure that includes new fossil fuel components.

** Dataset

We will be using publicly available US government data that has been cleaned and
made available through PUDL's pipeline. The data dictionary can be found [[https://catalystcoop-pudl.readthedocs.io/en/latest/data_dictionaries/pudl_db.html][here]].

** %-overforecast

To compute the % over-forecasted we'll need to divide the forecast by the
realized demand. To this end, let's drop any rows where the realized demand is
zero (and the forecasted demand is non-zero). There are also a few outliers,
where the over-forecasted percentage is over 1000%. I'll just drop those for
now.

#+begin_src python
df = df.filter(
    (pl.col("peak_demand_mw") != 0) | (pl.col("peak_demand_forecast_mw") == 0),
)
# remember null and NaN are different in polars!
df = df.with_columns(
    delta_pct=pl.col("delta_mw").truediv(pl.col("peak_demand_mw")).mul(100).round(1)
).filter((pl.col("delta_pct") < 1000) | pl.col("delta_pct").is_nan())
print(df)
